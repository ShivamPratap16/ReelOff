# ReelOff Privacy Policy

_Last updated: 1 October 2026_

ReelOff blocks short-form video (YouTube Shorts, Instagram Reels, Facebook Reels, Snapchat
Spotlight, TikTok and similar) and limits endless scrolling in apps the user chooses.

## Accessibility Service

ReelOff uses Android's AccessibilityService API. It uses the API only to:

- recognise when a short-video screen or a limited feed is on screen in an app the user selected,
  by reading view identifiers, content descriptions, the selected tab and, in web browsers, the
  address bar; and
- press Back or Home on the user's behalf when such a screen appears.

ReelOff does not read the text of messages, posts, comments, passwords or form fields. It does not
use the Accessibility API to collect data, change settings or interact with other apps beyond
pressing Back or Home.

## Data collection and sharing

ReelOff collects **no** personal data and shares **no** data with anyone. The app does not request
the Internet permission, so it cannot send data off the device.

The only things stored, locally on the device, are the user's settings and counts of how many
times content was blocked. Backups of this data are disabled. Uninstalling the app deletes it.

## Children

ReelOff does not knowingly collect any information from anyone, including children.
